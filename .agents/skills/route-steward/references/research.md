# External research

Use current authoritative sources for facts owned by VPS providers, cloud platforms, carriers, client applications, and upstream protocols. Useful checks include regions and prices, UDP and IPv6 support, firewall procedures, client import formats, and Cloudflare/Wrangler behavior.

Research supports recommendations and preflight context. The user authorizes purchases, resource changes, credential rotation, and destructive migration steps. Route Steward support is limited to the drivers, renderers, and operations returned by `capabilities`.

When browsing is unavailable, use local capability metadata and ask for any current fact needed to continue.
